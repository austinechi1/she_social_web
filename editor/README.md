# S.H.E. Social Editor Phase 5 Modular

This is the same working Phase 5 editor, split safely into separate files.

## Open it
Use VS Code Live Server and open `index.html`. Do not double-click the file.

## What was changed
- Outer CSS moved to `css/editor.css`
- Working editor JavaScript moved to `js/editor.js`
- Module placeholder files were added so features can be moved gradually without breaking the editor

## Important
For this first modular step, most logic is still inside `editor.js`. That is intentional. Test this first. Once it works, move one feature at a time into the smaller files.
