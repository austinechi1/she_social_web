# S.H.E. Social Website

Official website repository for **S.H.E. Social, LLC**, a social media management and content creation agency helping women entrepreneurs build a polished and consistent online presence.

## Live Website

Visit **[she-social.com](https://she-social.com)**.

## About S.H.E. Social

S.H.E. Social provides done-for-you social media support for busy business owners. Services include:

- Social media strategy
- Content planning and creation
- Short-form video recording and editing
- Reels, carousels, static posts, and stories
- Social media management
- Analytics and performance reporting
- Event content coverage

## Technology

The website is built with:

- HTML5
- CSS3
- JavaScript
- Netlify for hosting and deployment

## Main Files

- `index.html` contains the homepage structure and content.
- `styles.css` contains the homepage styling and responsive design.
- `script.js` contains navigation and user-interface functionality.
- `netlify.toml` contains Netlify configuration.
- `assets/` stores website images, video, and other media.
- `auth-redirect.js` supports authentication redirects for protected areas.

Additional folders support the client portal, onboarding, proposals, retreats, and other S.H.E. Social resources.

## Local Preview

Clone the repository and open `index.html` in a browser. You can also run it with a local development server, such as the Live Server extension in Visual Studio Code.

## Deployment

Changes pushed to the production branch are deployed through Netlify. Review updates carefully before pushing changes that may affect the live website.
